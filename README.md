# Routine

Komandas darba rīks ar publisku landing lapu un sānjoslas lietotni. Gaišs Next.js frontend.

**Current version:** `0.3.58`

## Palaist

```bash
npm install
npm run dev
```

Atver [http://localhost:3120](http://localhost:3120).

## Kas iekšā

- **Landing** — `/` ar dashboard vizuāli; TASQIN fallback nosaukums, SEO H1/title visās 15 valodās, sekundārais CTA uz `#features`; zem hero lazy load; hash saites slīd gludi; fīču kartītes un hero teksts tikai no ieslēgtajiem frontend moduļiem (izslēgtie netiek pieminēti); ja maksas plāni ieslēgti — galvenes **Cenas** un plānu kartītes vienādā augstumā (`#pricing`, pogas vienā līnijā, Early access atlicis/kopējais); Ienākt galvenē (un Reģistrēties, ja Resend aktīvs) un sīkdatņu popup; ielogotam uzreiz `/dashboard`
- **Valodas** — 15 UI valodas (lv, en, ru + DE/FR/ES/NL/DA/NO/FI/PL/LT/ET/IT/SV) ar vienādu atslēku komplektu; izvēlnē karogs un nosaukums, noklusējums pirmais, tad alfabēts; viesim bez prefiksa valodu ņem no pārlūka `Accept-Language` (piem. somu → `/fi`)
- **SEO / Search Console** — `/robots.txt` un `/sitemap.xml` (landing, legal un, ja docs ieslēgti, visi publiskie raksti × 15 valodām); kanoniskie URL no `NEXT_PUBLIC_SITE_URL`; hreflang visām valodām; landing JSON-LD `CollectionPage` + `TechArticle`; 1200×630 OG attēls; privātās lapas `noindex`; HTML tag verifikācija ar `GOOGLE_SITE_VERIFICATION`
- **Auth** — `/login`, `/signup`, `/forgot-password`, `/update-password`, `/auth/confirm`; e-pasts un parole tikai ja **Resend** ir konfigurēts un aktīvs (bez tā nav Reģistrēties joslā, signup saites loginā un Atcerēties mani; `/signup` uz `/login`); login/signup pogas nāk no publiska RPC (`public_sign_in_methods`), nevis service role; reģistrācijas apstiprinājums un paroles atjaunošana iet kā HTML e-pasts no admin šabloniem (ne Supabase noklusējuma); uzaicinājuma signup (`/signup?invite=…`) ar Google/Microsoft (ja ieslēgts) un/vai Vārds/Uzvārds un bloķētu e-pastu, ja konta vēl nav; paroles lauki ar rādīt/paslēpt; e-pasta signup aizpilda spēcīgu paroli un rāda stipruma joslu (vismaz Vidēja; sākot rakstīt savu paroli, atkārtotais lauks tiek notīrīts); **Turpināt ar Google** / **Turpināt ar Microsoft** (ja admin ieslēdzis OAuth) ved uz `/auth/google-oauth/sign-in` / `/auth/microsoft-oauth/sign-in` (GET, ar `?next=` no login lapas); verificēts OAuth e-pasts ielaiž esošu kontu ar to pašu adresi un piesaista provider; Microsoft prasa verificētu e-pastu; paroles lockout pēc neveiksmēm; **Cloudflare Turnstile** (ja admin ieslēdzis) - botu pārbaude e-pasta reģistrācijā un Google ienākšanā, ja vēl nav komandas; **Atcerēties mani** tikai loginā, pēc noklusējuma izslēgts (30 dienas ar ķeksi); ielogotam `/` ved uz dashboard; nezināma lapa (404) → `/dashboard`
- **Gmail spraudnis** — Chrome unpacked `extensions/gmail` (MV3 `0.4.50`): bez URL/Client ID; popup kartīte ar kontu, **Iziet** tikai kā ikona, centrētu loading, komandām un Drive/Gmail statusu (`{SYSTEM_NAME}`); paša sesija `chrome.storage.local` (~30 dienas); vietnes **Iziet** notīra tikai pārlūka cookie (bez GoTrue `/logout`), spraudni neatceļ; Google ielogošanās spraudnim izveido atsevišķu sesiju; spraudņa **Iziet** ir atsevišķi; Gmailā pogas tikai ja komandai ir pieslēgts ieslēgtais mākonis (Google Drive un/vai OneDrive); **Turpināt ar Google** atver `/auth/gmail-plugin/login` → vienā Google piekrišanā arī Gmail pieeja → `/auth/gmail-plugin/done` (TOTP, ja 2FA ieslēgta; bootstrap ticket paliek, arī ja cilni aizver); **Atjaunot Gmail** (reconnect) caur ticket bridge → `/auth/gmail-plugin/start`; 3. solī var izvēlēties esošu apakšuzdevumu vai **Jauns apakšuzdevums** (atver jaunu modāli: nosaukums, sākums, termiņš, statuss, atbildīgais ar live meklēšanu, apraksts; izveide notiek tikai ar **Pievienot** un pielikumiem; katram atzīmētajam failam var ierakstīt savu piezīmi); login ar `?next=` atgriež pie Gmail OAuth; OAuth login/signup caur `/auth/google-oauth/sign-in` un `/auth/microsoft-oauth/sign-in`; savienojums caur `/auth/google-plugin/callback` (integrācija **Google Plugin**); noklusējums `www.tasqin.com`; pēc spraudņa Reload jāpārlādē Gmail cilne; `/api/extension/*` CORS; admin modulis **Gmail spraudnis**
- **MFA** — profilā pēc izvēles visiem; ja ieslēgta, pie ielogošanās TOTP 3+3 ciparu bloki ar automātisku pārbaudi; **Iziet** kā ikona; sistēmas adminam MFA obligāta `/admin`
- **Legal** — `/privacy`, `/terms`, `/cookies` ar fiksētu satura sānjoslu; privātuma kontaktam e-pasts no admin uzstādījumiem; kājene arī lietotnē
- **Dokumentācija** — publisks `/docs` ar sānjoslu visās valodās; mobilajā (zem 1024px) sānjosla pazūd, burger poga augšā pa kreisi atver overlay; attēli mobilajā 100% no teksta platuma, datorā 50% un iecentrēti, vispirms mazs izplūdis priekšskatījums tad pilnā kvalitāte, klikšķis pietuvina; admin `/admin/docs` kategorijas un apakškategorijas (Markdown, attēli, vilkšana, `{SYSTEM_NAME}` vietnieks, valodu cilnes tulkojumiem) ar loading, kad atver rakstu, un progress joslu, kad augšupielādē attēlus; publiski nosaukums treknrakstā un lielajiem burtiem; kājenē **Documentation**, kad ieslēgts
- **Sānjosla** — mobilajā (zem 1024px) pazūd, burger poga atver overlay; ceļa joslas vietā komandas avatars un nosaukums (var pārslēgt komandu); tooltipi nerādās; Sākums ved uz `/dashboard` (live meklēšana visiem uzdevumiem/apakšuzdevumiem pēc nosaukuma, apraksta, kontrolsaraksta un pielikuma nosaukuma, arī arhīvā; Mani uzdevumi, ja ir piesaistīti, ar personīgo **Atlikt**; tad darbs pa sarakstiem); sadalītie uzdevumi un apakšuzdevumi pēc statusa pretēji picker (aktīvākie vispirms, TO DO beigās); kokā var ievilkt mapē, iznest ārā vai nomest zem pēdējās mapes; uzdevuma/mapes `...` → **Arhivēt**; rindas fona aizpildījums rāda progresu (pabeigtie + esošie); apgrieztiem nosaukumiem overflow tooltip; apakšā virs Failu vietas: **Atrast kļūdu?**, **Pieprasīt funkciju** (citu pieprasījumi + UP balsis), **Atsauksmes** — e-pasts uz juridisko e-pastu
- **Trīs skati** — Saraksts (kopsavilkums ar `done/total` un vienu joslu; mape summē uzdevumus; aiz nosaukuma/arhīva `+` atver jauna apakšuzdevuma modāli), projekts (Uzdevumi | Faili augšā, Saraksts zem tiem ar mapēm, progresu, arhīvu kartītē un **Vēsture**; Uzdevumi bloka arhīvs pārslēdz visas Saraksts kartītes), uzdevums (apakšuzdevumu tabula ar progresu virsrakstā un to pašu `+`)
- Sānjoslas koks rāda sarakstus, uzdevumus un apakšuzdevumus; apakšuzdevumu aplītis un Saraksta loga teksts ir statusa krāsā; klikšķis uz apakšuzdevuma nosaukuma atver modāli, uz statusa ikonas — statusa izvēlni
- Saraksta `...` → **Statusi** — sistēmas statusi visiem sarakstiem un komandas statusi tikai šim sarakstam; **Automatizācijas** (ja ieslēgts modulis) — piem. jaunai mapei automātiski pielietot šablonu
- **Komanda** — sānjoslas koks paliek redzams (vārdi, tiešsaiste); klikšķis uz **Komanda** un lietotājiem atver `/team` tikai ar pieeju **Komanda** (`nav.team`; bez tās lapa slēgta, savu profilu var atvērt); `+` tikai ar **Uzaicināt** (`team.invite`); ja nav brīvas vietas maksas plānā, uzaicināšana automātiski iegādā 1 vietu (spinner, apstiprinājums); `...` tikai ar lomām, veidnēm vai Drive; lomas (1 pieeja) un **pienākumi** (N amata birkas, piem. komandas vadītājs, tāmētājs) — uzdevumus un privātos sarakstus var piesaistīt arī pēc pienākuma; uzaicināšana (jaunam e-pastam vajag ieslēgtu Resend un HTML e-pastu ar `/invite/{token}`; ja konta nav — `/signup?invite=…` ar Google/Microsoft vai paroles reģistrāciju; reģistrētam in-app paziņojums); apstiprinājums/noraidījums paziņojumos vai uzaicinājuma lapā; pending lietotāji `/team`, bet ne sānjoslā; resend, kopēt linku, noņemt pending; ar pieeju **Noņemt lietotājus** (`team.members.remove`) noņem arī apstiprinātus no `/team` (ne vadītāju, ne sevi); noņemšana maksas plānā atstāj brīvu apmaksātu vietu līdz cikla beigām (vadītājam globāls baneris); **neapmaksāts abonements** — parastiem lietotājiem blur + modālis (var pārslēgt komandu vai izveidot jaunu); sānjoslas navigācija bloķēta, bet komandas pārslēdzējs, lietotāja izvēlne un atbalsta saites paliek; vadītājam sarkans globāls baneris; vadītājs var **Iecelt par vadītāju** citu apstiprinātu lietotāju (lomas apmaiņa); lietotājs var pats pamest komandu (ne vadītājs); bez komandas — dashboard ar jaunas komandas pogu un paziņojumu hintu; lomas ar pieejām; sānjoslā aiz Komanda **Abonementi** (`/team/billing`, ja maksas plāni ieslēgti un `team.settings.edit`, **nav** VIP komandai; vadītāja vieta bez maksas) ar vietu skaitu, checkout kopsavilkumu (maksas lietotāji, summa, + PVN), info par prorata rēķinu jauniem lietotājiem, mēneša/gada toggle, nākamo rēķinu un 1 vietas iegādi; **Atteikties no abonementa** perioda beigās (Stripe) un atjaunošana; salokāma pārvaldība kopsavilkuma kartē; dzeltens countdown, ja abonements beidzas (neaizpildīta vieta nākamajā ciklā vairs nav; bez brīvas vietas uzaicinājums slēgts, līdz vieta ir apmaksāta); `...` → **Šabloni** (`/templates`, ja ieslēgts modulis), **Google Drive Integrācija** (ja `module_google_drive` + failu augšupielāde; faili uz Drive, bez servera baitiem), **OneDrive** (ja ieslēgts) — assignee, checklist, custom apakšuzdevumu statusi, automātiska saglabāšana
- **Sarakstu pieejas** — sākumā noklusējuma līmenis visiem; pēc izvēles pielāgo katrai lomai (pilna labošana, labot, komentēt, tikai skatīt); privātu sarakstu (tikai izvēlētajiem lietotājiem/lomām) var ieslēgt, ja aktīvs privāto sarakstu modulis
- **Komandu lomas un pieejas** — katrai lomai definē sadaļu redzamību un darbības (saraksti, uzdevumi, šabloni, faili, komandas pārvaldība); divkolonnu izkārtojums, toggle automātiski saglabā
- **Admin** — `/admin` `is_admin` lietotājiem; joslā trīs kategorijas (**Cilvēki**, **Katalogs**, **Sistēma**) ar hover dropdown (lietotāji, komandas, lomas, statusi, failu tipi, valodas, tulkojumi, **Docs**, **Paziņojumi**, **moduļi**, **maksas plāni**, **integrācijas**, **e-pasta šabloni**, **cron jobs**, uzstādījumi); `/admin/announcements` — globāli paziņojumi ar termiņu un ieslēgumu; lietotājiem aizverams bloks (sīkdatne līdz termiņam); `/admin/email-templates` — HTML šabloni (reģistrācija, parole, uzaicinājums, sistēmas paziņojumi) visās valodās ar priekšskatījumu; `/admin/integrations` — Google OAuth, **Google Plugin** (Gmail spraudnis), Microsoft OAuth, Cloudflare Turnstile (Site Key + Secret), Resend (From + Reply-To + API Key), Umami, Sentry, Stripe (Publishable + Secret + webhook); nederīga Stripe atslēga rāda globālu baneri tikai `is_admin` (saite uz Integrācijām); aktīvs Umami ielādē skriptu pēc hidratācijas (pageview pēc statistikas piekrišanas); aktīvs Sentry ķer klienta kļūdas; `/admin/cron-jobs` — ieslēgt sākuma/termiņa atgādinājumus (slēdzis rāda loading) un kopēt cron-job.org saiti (**reizi stundā**; sākums no 8:00 un termiņš no 9:00 lietotāja joslā; līdz 1000 lietotājiem palaišanā); `/admin/modules` ieslēdz/izslēdz privātos sarakstus, failu augšupielādi, **Pārsūtīt failu**, Google Drive, **Gmail spraudni**, Check List, automatizācijas un šablonus; `/admin/payment-plans` — plānu katalogs (`free` ar lietotāju limitu, `paid` cena par lietotāju mēnesim/gadam, moduļi); ieslēgt tikai ar konfigurētu un ieslēgtu Stripe; izmēģinājums un Early access vietu limīts; ieslēgtiem plāniem komandas redz tikai plāna moduļus un landing rāda **Cenas**; `/admin/teams` — plāna piešķiršana un VIP zvaigzne (bez maksas un limitu); `/admin/settings`: nosaukums, juridiskais e-pasts, Resend From/Reply-To (ja konfigurēts), slogans, logotips/favicon vai iniciāļu avatārs, datumu/laika noklusējums; pārlūka cilne `Sākums | Routine` (no `generateMetadata`, nevis klienta pārrakstīšanas)
- **Personīgā informācija** — lietotāja izvēlnē modālis vārda un uzvārda maiņai (sinhronizē profilu visās komandās)
- **Paziņojumu uzstādījumi** — lietotāja izvēlnē vai zvaniņa paneļa settings pogā; grupēts modālis (Uzdevumi / Atgādinājumi / Komanda) ar ikonām; toggle automātiski saglabā
- **Kalendāra integrācija** — lietotāja izvēlnē (ja `module_calendar` + Apple vai Google); `.ics` abonēšana piesaistītajiem uzdevumiem ar termiņu (bez apraksta teksta); pilnais URL rādās tikai ģenerēšanas brīdī
- **Personīgie uzstādījumi** — `/settings/profile`: nedēļas sākums, datuma formāts/atdalītājs, 12/24 h; lietotāja vērtība pārspēj sistēmas; tukšs lauks = sistēmas noklusējums; **Dzēst kontu** ar 30 dienu deaktivizāciju (pieslēdzoties atkārtoti konts automātiski atjaunojas)
- **Faili** — kokā un apakšuzdevumos tikai atļautie paplašinājumi (sākumā pdf, dwg, Word, Excel, png/jpg/jpeg/gif/webp, txt/html, zip/rar); ikona un krāsa no `/admin/file-types`; augšupielādē progressa logs; ar Drive vai OneDrive — saturs mākonī, ne serverī; UI nosauc tikai ieslēgtos mākoņus; pārsaukšana atjaunina arī mākoņa faila nosaukumu (paplašinājumu mainīt nevar); klikšķis: bildes/PDF/txt → priekšskatījuma modālis, Excel u.c. → lejupielāde; ielādes laikā overlay ar spinneri; **Lejupielādēt** pogā loading, kamēr fails nāk; nosaukumi ar latviešu burtiem (ē, ķ) vairs nesalauž Drive/OneDrive atbildi; PDF bez sānjoslas; e-pasta `.txt` rāda kā e-pastu; apakšuzdevuma pielikumos izmērs, piezīme kā tooltip uz kartītes (`…` → **Piezīme**), apgrieztam nosaukumam tooltip, X dzēš pēc apstiprinājuma, `...` → Lejupielādēt un (ja `module_send_file` un Resend) **Pārsūtīt failu** e-pastā ar PATH tēmu; From = `Vārds Uzvārds <Resend From>`, Reply-To = `Vārds Uzvārds <lietotāja e-pasts>`, HTML galvene ar `(e-pasts)` (vēsturē: fails; e-pasts, tēma un ziņojums katrs savā rindā ar truncate/tooltip; bounce/failed sarkanā ar **Nosūtīt vēlreiz**); sānjoslā failu vietas summa (tooltip: Serveris / Cloud); mapes **Faili** logs ietver arī apakšuzdevumu pielikumus; paperclip aiz nosaukuma tabulā un mapes Sarakstā, ja ir pielikumi; ja failu modulis izslēgts, upload, Failu logs un Failu vieta nav
- Ceļa joslā pirms katra posma tipa ikona (saraksts, mape, uzdevums, fails); aiz paziņojumiem valodas kods, ja ir vairākas aktīvas valodas; bez izvēles rāda sistēmas noklusējumu
- Apakšuzdevuma tabula: viena tabula ar statusu grupām un zilu drop līniju; arhīvs pie Pievienot (aktīva poga sarkanīga); pabeigtajiem un dzēstajiem viegls rindas fons; fade-out, dzēšana/atjaunošana, pārvietošana; aiz nosaukuma paperclip, ja ir pielikumi (arī mapes Saraksta skatā); zem nosaukuma un pārvietošanas izvēlnē mapes/saraksta **PATH**, ja uzdevums nav saraksta saknē; sarakstā klikšķis atver modāli; statuss saglabājas uzreiz; sākuma/termiņa datumi rāda atlikušās vai kavētās dienas pēc statusa grupas (Nav sākts / Aktīvs / Slēgts); modālī **vēsture** ar izmaiņu žurnālu (bez komentāriem); mobilajā Detaļas / Vēsture cilnes, PATH visā platumā
- **Check List** apakšuzdevuma modalī pirms pielikumiem; tukšs sākumā sakļauts; slēgto statusu tikai pie 100% (ja Check List modulis ieslēgts); zem statusa pogas zaļa progresa josla
- Satura joslā **paziņojumi** (zvaniņš labajā malā) — personīgie brīdinājumi par uzdevumiem, kur esi iesaistīts (arī piešķiršana no šablona/automatizācijas), komandas uzaicinājumi ar Apstiprināt / Noraidīt, un vadītājam brīva apmaksāta vieta (`seat_open`); ja Resend ir aktīvs, tos pašus notikumus (izņemot uzaicinājumu, kam ir savs šablons) sūta arī e-pastā
- Kamēr dati ielādējas, rādās **Ielādē…** ar spinneri (lapas, sānjosla, paziņojumi), ne tukšs saturs; pēc ielogošanās vispirms nāk sarakstu čaula, failu saturs un uzdevuma vēsture - tikai atverot
- Darba dati Postgres (`teams`, `work_lists`, `work_tasks`, …); Google sesija un `public.users` caur Supabase

## Skripti

| Komanda | Apraksts |
|---|---|
| `npm run dev` | Izstrāde, ports **3120** |
| `npm run start` | Produkcijas serveris, ports **3120** |
| `npm run build` | Produkcijas būve |
| `npm run typecheck` | TypeScript pārbaude |
| `npm run i18n:check` | Visām valodām visas tulkojumu atslēgas un placeholderi |
| `npm run lint` | ESLint |
| `npm run audit:check` | HIGH/CRITICAL atkarību pārbaude |
| `npm run db:test` | Pieslēgums Supabase Postgres un `public` tabulu saraksts |
| `npm run db:migrate` | Pending `supabase/migrations/*.sql` |

Kopē `.env.example` uz `.env.local`. `NEXT_PUBLIC_SUPABASE_URL` ir projekta hosts (`https://….supabase.co`), bez `/rest/v1/`. Produkcijā `NEXT_PUBLIC_SITE_URL` = viens kanoniskais hosts (`https://tasqin.com` vai `https://www.tasqin.com`). Vercel env: bez pēdiņām, `SUPABASE_SERVICE_ROLE_KEY` ir **service_role** (ne anon). Pārlūka kods lasa `NEXT_PUBLIC_*` tikai kā statisku `process.env.NEXT_PUBLIC_…` (citādi MFA/klients redz tukšu env). Pēc `NEXT_PUBLIC_*` izmaiņām **Redeploy**. Detalizēti: [DEVELOPER.md](DEVELOPER.md#vercel).

Tehniskā dokumentācija: [DEVELOPER.md](DEVELOPER.md). Drošības audits: [`security-check.md`](security-check.md), uzlabojumu saraksts: [`system_security_upgrades.md`](system_security_upgrades.md). Izmaiņu vēsture: [CHANGELOG.md](CHANGELOG.md).
